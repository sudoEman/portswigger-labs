# PortSwigger Web Security Academy Labs

Hands-on security labs completed through PortSwigger Web Security Academy, documenting practical exploitation techniques, HTTP request analysis, vulnerability research, and key security concepts.

## Topics Covered

* Authentication vulnerabilities
* SQL Injection
* Access Control
* Information Disclosure
* Other web security vulnerabilities

## Purpose

This repository documents my practical web security learning through PortSwigger labs.

Each write-up focuses on:

* Understanding the vulnerability
* Identifying the attack surface
* Analyzing HTTP requests and responses
* Reproducing the vulnerability
* Understanding why the exploit works
* Documenting key takeaways

## Tools

* Burp Suite
* Browser Developer Tools
* PortSwigger Web Security Academy

## Disclaimer

All testing documented in this repository was performed against intentionally vulnerable PortSwigger Web Security Academy labs or other authorized environments.

This repository is for educational and defensive security learning purposes.
